# AgentRemote

Windows x64 桌面客户端发布仓库。

在 [Releases](https://github.com/RiceM001/AgentRemote/releases/latest) 下载便携版，解压后运行顶层 `AgentRemote.exe`。

软件更新入口位于左侧栏底部、本机设备信息上方。2.1.13/2.1.14 在「设置与日志 → 软件更新」，更旧版本需首次手动安装。

更新包通过 Ed25519 签名与 SHA-256 校验，支持断点续传、有限重试、系统代理/直连回退及 GitHub 官方备用入口。完整缓存包可离线安装；GitHub 完全不可达且没有完整缓存时，保留当前版本并提示稍后重试。

更新会重新打开面板及关闭其中的远程查看窗口，不注销独立画中画会话，不停止正在运行的远程后台、游戏或脚本。后台组件在下次正常启动时使用新版。新版初始化失败时尝试恢复旧面板。

此仓库仅发布安装包、签名清单和使用说明，不包含设备配对信息、访问凭据及发布签名私钥。
